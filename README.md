# Win Amateur Front

Base local creada con React, TypeScript y Vite. La dirección visual se definirá antes de construir componentes o pantallas.

## Ejecutar en local

```bash
npm install
cp .env.example .env
npm run dev
```

El archivo `.env` es local y Git lo ignora. Configura allí la URL del backend:

```dotenv
VITE_API_BASE_URL=http://localhost:8080
```

Abre la URL que muestra Vite, normalmente `http://localhost:5173`.

## Comandos

```bash
npm run dev      # servidor de desarrollo
npm run build    # compilación de producción
npm run lint     # análisis estático
npm run preview  # vista previa de la compilación
```
